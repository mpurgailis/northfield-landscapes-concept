# Northfield Landscapes concept
A reusable high-conversion landscaping website concept, informed by the composition and interaction patterns of a strong service-business reference, with fully original identity, copy and image selection.

## Run
Open `index.html` or serve this directory with any static server.

## Reuse
Replace the identity, location, phone/email, project imagery and service copy. Design tokens live at the top of `styles.css`.
